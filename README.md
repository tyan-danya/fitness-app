# ФитДневник

Android-приложение для учёта силовых тренировок и питания (КБЖУ). Всё хранится локально (Room/SQLite), интернет не нужен.

## Возможности

- **Тренировки**: старт/финиш с таймингом, запись подходов «вес × повторы» по каждому тренажёру, номер подхода проставляется автоматически.
- **Прогресс в реальном времени**: на экране упражнения виден результат прошлой тренировки и сравнение подход-к-подходу (↑/↓/=), личные рекорды (по весу и расчётному 1ПМ по Эпли) отмечаются бейджем.
- **Контрольное взвешивание** при завершении тренировки + история веса с графиком.
- **Таймер отдыха** между подходами: автозапуск после записи подхода, вибрация, «+15 с», настраиваемая длительность.
- **Питание**: дневник по дням с КБЖУ, суточные итоги и цели (калории/Б/Ж/У), быстрый повтор недавних блюд.
  - Приёмы группируются на **завтрак / обед / ужин / перекус**: тип ставится автоматически по времени (4–11 завтрак, 11–16 обед, 16–22 ужин, иначе перекус), меняется чипом в форме или **перетаскиванием карточки** (долгое нажатие) в другую секцию; «+» в заголовке секции добавляет сразу в неё.
  - КБЖУ вводится **на 100 г + вес порции** (как на упаковке) — итог считает приложение; режим «вся порция» для готовых блюд. Недавние блюда помнят значения на 100 г — достаточно ввести новый вес.
  - **Расчёт через ИИ**: в меню ⋮ → «Расчёт через ИИ…» задаётся API-ключ, модель и базовый URL любого OpenAI-совместимого сервера (chat/completions); кнопка «Рассчитать через ИИ» в форме заполняет КБЖУ на 100 г и, если вес не указан, типичный вес порции. Интернет нужен только для этой кнопки.
  - **Рассчитать позже**: приём сохраняется без КБЖУ (⏳), «Выгрузить для расчёта» отдаёт JSON-файл с такими приёмами ассистенту, «Загрузить расчёт из файла» применяет заполненный файл того же формата.
- **Замеры**: отдельная вкладка для сантиметровой ленты — талия, грудь, бёдра, руки, ноги и т.д. Набор зон выбирается в настройках (хоть одна талия). Запись «сессии» замеров одной формой, карточка каждой зоны с текущим значением, изменением с прошлого раза и за 30 дней, графиком и историей с удалением. **Напоминание**: если замеров не было N дней (по умолчанию 3), в заданный час приходит уведомление со звуком; тап по нему открывает вкладку.
- **Статистика**: календарь с маркерами тренировок и питания, детали дня, график веса, тоннаж по неделям, график прогресса по упражнению, история тренировок. Графики — с «круглыми» делениями оси Y, датами по оси X, нулевой базовой линией у столбиков и минимальным охватом шкалы (вес ±1 кг), чтобы динамика в 1–2 кг была видна.
- **Экспорт**: JSON (полный, для анализа) и CSV (подходы, питание, вес, замеры — для Excel) через системный шаринг.

## Сборка

Используется переносной тулчейн из `G:\toolchain` (JDK 17, Android SDK 35, Gradle 8.11.1):

```powershell
.\build.ps1 assembleDebug    # отладочный APK
.\build.ps1 assembleRelease  # подписанный релизный APK
.\build.ps1 test             # юнит-тесты (Robolectric)
```

APK попадает в `app/build/outputs/apk/<variant>/`.

## Архитектура

- Kotlin, Jetpack Compose (Material 3), Navigation Compose.
- Room (6 таблиц: exercises, workouts, workout_sets, meals, weight_entries, body_measurements; схема v4, миграции в `AppDatabase`), каталог упражнений предзаполняется при первом запуске.
- Напоминание о замерах — `reminder/MeasurementReminder.kt`: AlarmManager (неточный ежедневный будильник) + BroadcastReceiver (перепостановка после перезагрузки) + NotificationChannel с уровнем HIGH; без WorkManager.
- Графики — чистые `DrawScope`-функции в `ui/stats/ChartDrawing.kt` (шкала `niceAxis`, подписи дат), Composable-обёртки в `Charts.kt`. `ChartRenderTest` рисует их в PNG (`app/build/chart-renders`) под Robolectric NATIVE — можно смотреть глазами.
- Расчёт КБЖУ через ИИ — `data/ai/NutritionEstimator.kt` (HttpURLConnection, json_schema с откатом на json_object); файл-обмен — `export/EstimateExchange.kt`.
- MVVM: ViewModel + StateFlow, ручной DI через `AppContainer` (см. `FitDiaryApp`).
- Доменные расчёты (1ПМ, тоннаж, стрик) — чистые функции в `domain/Calculations.kt`; типы приёмов и пересчёт «на 100 г ⇄ порция» — `domain/Nutrition.kt`.
- Тесты: JUnit4 + Robolectric (`sqliteMode=NATIVE`) + Truth + coroutines-test.
